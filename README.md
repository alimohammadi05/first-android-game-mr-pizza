# Mr. Pizza 🍕

**Mr. Pizza** is a simple and engaging Android mobile game developed using the powerful **Godot Engine** and compiled specifically for the Android platform.

---

## 🛠️ Technologies & Skills Utilized

* **Game Engine:** Godot Engine (utilizing `project.godot` configuration and `.godot` internal system files)
* **Target Platform:** Android (compiled into a ready-to-install `Mr. Pizza.apk` package)
* **Asset Management:** Organized `assets` directory containing game graphics, audio, and visual elements
* **Version Control:** Git & GitHub (configured with custom `.gitignore` and `.gitattributes` files)
* **Mobile Export Configuration:** Customized `export_presets.cfg` for streamlined Android builds

---

## 📂 Project Structure

Android_Game_Mr. Pizza/
├── .godot/              # Godot engine cache and internal project files
├── android/             # Android build templates and dependencies
├── assets/              # Game assets (sprites, audio, scenes)
├── export_presets.cfg   # Android export templates and settings
├── project.godot        # Main Godot project configuration file
└── Mr. Pizza.apk        # Compiled Android installation package

---

## 🚀 How to Run & Develop

1. Install **Godot Engine** on your workstation.
2. Open the project folder by importing `project.godot` into Godot.
3. Modify scripts, scenes, or assets, and utilize the export configurations to build an updated `.apk` for your Android device.# first-android-game-mr-pizza
